# هم‌رسان (HamResan)

**وضعیت: نمونهٔ اولیهٔ کتابخانهٔ هسته، نه اپ قابل نصب یا MVP کامل.** مخزن در آغاز خالی بود. فعلاً هیچ برنامهٔ MAUI، رابط فارسی، کشف دستگاه، جفت‌سازی، تاریخچه، سرویس Android یا بستهٔ Windows وجود ندارد. انتقال بین دستگاه‌های واقعی و امنیت انتها به انتها تأیید نشده‌اند. از این کد برای انتقال دادهٔ واقعی استفاده نکنید.

یک سازنده و اعتبارسنج کد دعوت طولانی و یک‌بارمصرف نیز در هسته وجود دارد، اما هنوز به هیچ اتصال شبکه یا رابط کاربری وصل نشده است.

هستهٔ C# شامل قاب‌بندی کنترل JSON، اعتبارسنجی پیشنهاد، انتقال جریانی، هش SHA-256، فایل موقت و جلوگیری از بازنویسی، تأیید گیرنده به‌صورت callback، و اتصال TLS دوطرفه با fingerprint از پیش تأییدشده است. این‌ها فقط زیرساخت هستند؛ انتخاب و تأیید امن fingerprint در برنامه پیاده‌سازی نشده است.

## ساخت و آزمون هسته

روی سیستمی با SDK پایدار .NET 10:

```sh
dotnet build tests/HamResan.Core.Tests/HamResan.Core.Tests.csproj -c Release
dotnet run --project tests/HamResan.Core.Tests/HamResan.Core.Tests.csproj -c Release --no-build
```

این فرمان‌ها در محیط فعلی اجرا نشده‌اند؛ SDK نصب نیست و دانلود رسمی آن به‌دلیل محدودیت شبکه ممکن نبود. نصب و اجرای Android و Windows در حال حاضر ممکن نیست: ابتدا باید اپ و adapterها ساخته شوند. پس از آن، ساخت به Windows با Visual Studio، workloadهای MAUI و Android و Windows SDK سازگار و دستگاه‌های واقعی نیاز خواهد داشت.
